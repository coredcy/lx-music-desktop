# 自定义音源配置

`user_api.json` 是当前 LX Music 开发实例导出的自定义音源数据，共 11 个源。它只包含音源配置与脚本；不包含播放列表、播放缓存或应用偏好设置。

## 用于打包后的应用

1. 首次启动打包后的应用一次，然后从托盘**完全退出**，让应用创建数据目录。
2. 打开应用数据目录中的 `LxDatas` 文件夹：

   - 普通安装版通常是 `%APPDATA%\lx-music-desktop\LxDatas\`。
   - 便携版需要在 EXE 同级预先创建 `portable` 文件夹，数据目录是 `portable\userData\LxDatas\`。

3. 先备份目标目录原有的 `user_api.json`。
4. 将本目录的 `user_api.json` 复制到目标 `LxDatas` 目录并覆盖同名文件。
5. 重新打开应用，在“设置 → 自定义源管理”确认源列表已加载。

此操作会**替换**目标应用原有的全部自定义源，不会合并两份配置。

## 注意事项

- 这些是第三方脚本，初始化成功不代表每个平台、每首歌或每种音质都能播放；服务端也可能临时波动。
- 仅保留和使用你信任的源。若要更新此文件，请通过应用的自定义源管理重新导出或替换配置后，再同步此文件。
- 开发模式的配置目录是 `%APPDATA%\Electron\LxDatas\`，与打包版的数据目录不同。
